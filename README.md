# ARENA // ONE

A browser-based first-person arena shooter against one computer-controlled drone.

## Gameplay

Both sides start with 100 health, and each successful hit deals 10 damage. Move around the arena's obstacles, avoid the drone's shots, and reduce its health to zero to win. Three healing stations appear in random locations each round; each can be used once to restore 30 health.

## Controls

- **↑ / ↓** — move forward or backward
- **← / →** — turn left or right
- **Space** — shoot

Touch controls are available on smaller screens.

## Play locally

Open `dist/index.html` in a browser. The game uses HTML, CSS, JavaScript, and Canvas; no build step is needed.
